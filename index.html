P2P Chat Code source sur GitHub

Des messages qui vont directement d'un téléphone à l'autre.

Messages, appels audio et appels vidéo, chiffrés de bout en bout et envoyés directement quand c'est possible. Personne d'autre que ton contact ne peut les lire ni les écouter.

Installer l'app Comment ça marche

Installer P2P Chat

Gratuit, sans compte e-mail ni numéro de téléphone. Les versions Android et iPhone se parlent entre elles.

Android Ton appareil Android 8 ou plus récent

Application native, à installer depuis le fichier APK.

Télécharger l'APK
  1. Ouvre le fichier p2p-chat.apk une fois téléchargé.
  2. Si Android le demande, autorise ton navigateur à installer des applications.
  3. Touche Installer, puis ouvre P2P Chat et choisis ton nom d'utilisateur.

iPhone Ton appareil iOS 16.4 ou plus récent

Application web qui s'installe sur l'écran d'accueil, sans passer par l'App Store.

Ouvrir l'app dans Safari
  1. Ouvre l'app avec Safari.
  2. Touche le bouton Partager .
  3. Choisis « Sur l'écran d'accueil », puis Ajouter.

Sur ordinateur ? Scanne ce code avec ton téléphone pour ouvrir cette page. L'app web fonctionne aussi dans Chrome, Edge ou Firefox, à cette adresse : ouvrir l'app web.

Comment ça marche

Ton téléphone crée tes clés
À l'inscription, ton appareil génère une paire de clés. La clé privée ne quitte jamais ton téléphone ; seule la clé publique est publiée, avec ton nom d'utilisateur.
L'annuaire sert à se trouver
Un petit serveur garde les noms et clés publiques, et transmet la poignée de main qui permet aux deux téléphones de se connecter. Il ne voit et ne stocke aucun message.
Les messages partent en direct
Une fois connectés (WebRTC), les deux téléphones échangent les messages chiffrés (X25519 + AES-256-GCM) sans intermédiaire. L'historique reste sur ton appareil.
Les appels aussi
Le son et l'image circulent directement entre les deux appareils, chiffrés par WebRTC. La négociation de l'appel est elle-même chiffrée avec la clé de ton contact, pour que l'annuaire ne puisse pas s'intercaler.

Bon à savoir

  • App fermée ? Tu reçois quand même une notification pour chaque message et chaque appel, après avoir activé les notifications dans l'app. Sur iPhone, l'app doit d'abord être ajoutée à l'écran d'accueil.
  • Messages hors ligne : si ton contact n'est pas connecté, ton message est gardé chiffré sur le serveur (illisible pour lui) jusqu'à ce que son téléphone le récupère, puis supprimé.
  • Appels : ils arrivent sous forme de notification avec Répondre / Refuser. L'écran d'appel plein écran sur téléphone verrouillé est réservé aux apps natives.
  • Certains réseaux mobiles bloquent les connexions directes ; un relais chiffré prend alors le relais s'il est activé sur le serveur.
  • Projet en version 0.1 : le chiffrement n'a pas encore de confidentialité persistante et n'a pas été audité.
